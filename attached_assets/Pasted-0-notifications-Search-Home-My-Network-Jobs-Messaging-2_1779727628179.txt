LeafAI – Plant Disease Detection & Treatment Recommender

Feb 2026 – Feb 2026


Associated with Iqra University (Official)

LeafAI is a deep learning-powered system designed to identify diseases in plant leaves and suggest potential treatments. The project leverages convolutional neural networks (CNNs), specifically a MobileNetV2 backbone, for efficient and accurate image classification.

Key highlights:
	•	Trained on 16,000+ images of healthy and diseased plant leaves using the PlantVillage dataset.
	•	Utilizes transfer learning with MobileNetV2 for faster convergence and high accuracy on limited data.
	•	Outputs disease predictions with confidence scores, helping in early detection and timely intervention.
	•	Designed as a Streamlit web app, offering a user-friendly interface for uploading leaf images and receiving instant results.
	•	Focused on practical applications in agriculture, enabling farmers, researchers, and agritech professionals to make data-driven decisions.
	•	Optimized for speed and accuracy, ensuring real-time predictions even on standard hardware.

Technologies & Tools:
	•	Python, TensorFlow/Keras
	•	MobileNetV2 (Transfer Learning)
	•	OpenCV & PIL for image preprocessing
	•	Streamlit for web app interface
	•	Pandas & NumPy for data manipulation

Impact:
LeafAI demonstrates the power of AI in agriculture, bridging machine learning and real-world problem solving. By detecting plant diseases early, it contributes to crop protection, yield improvement, and sustainable farming practices.

Skills: Artificial Intelligence (AI), Machine Learning, +1 skill

ClimaCast – Weather Forecasting PWA & Android App

Jan 2026 – Jan 2026


Associated with Iqra University (Official)

I developed ClimaCast as my semester project during my Bachelor’s in Computer Science and is a modern, responsive weather forecasting application built as a Progressive Web App (PWA) and deployed as an Android application using a single shared codebase.

The application delivers real-time weather updates, hourly and daily forecasts, location-based weather detection, favorite city management, unit conversion, and offline functionality through efficient caching strategies and service workers.

The project was implemented using React, TypeScript, and Tailwind CSS, integrated with external weather APIs for live data, and packaged into a native Android APK using Capacitor. Development emphasized performance optimization, accessibility, responsive UI design, and hybrid architecture efficiency.

This project demonstrates practical experience in modern web technologies, API integration, PWA development, mobile deployment, and user-centered application design, with a strong focus on real-world usability and scalability.

Simulated Phishing & Keylogging Attack Demonstration (Cybersecurity Awareness & Risk Mitigation)

Aug 2025 – Aug 2025

Developed and executed a short awareness project demonstrating a Simulated Phishing Attack and Keylogging to highlight a critical vulnerability in digital systems: human error. This project was designed to promote robust Cybersecurity Awareness and educate users on preventative measures.

Key Contributions & Skills Demonstrated:

Security Training & Awareness: Created visually engaging content to train non-technical users on identifying and avoiding fake login portals (as shown in the attached visual demo using the fictitious "urGovernment App").

Risk Management & Mitigation: Clearly communicated the Golden Rule of security: Never enter credentials on suspicious sites, and advocated for essential controls like Multi-Factor Authentication (MFA) and stringent URL Verification.

Threat Emulation: Built a demonstration environment to simulate the Attacker View, capturing keystrokes (username: admin | password: admin) to show the real-time danger of credential harvesting.

Goal: To foster a security-first culture ("Cybersecurity is everyone's job") and significantly reduce the threat surface area by addressing the single largest point of failure the user.

Skills: Cybersecurity

Enterprise-Level Multi-Protocol Network Design and Implementation

Apr 2025 – Apr 2025


Associated with Iqra University (Official)

In this project, I designed and implemented a large-scale enterprise network topology using Cisco Packet Tracer. The network integrates multiple protocols and technologies to ensure scalability, security, and efficient data flow across various departments.

Key Features of the Project:
	•	🌐 Hierarchical Network Design: Multiple interconnected LANs and WAN segments representing enterprise-level departments.
	•	⚙️ Routing Protocols:
	•	RIP for small-scale routing.
	•	OSPF (Multi-Area) for scalability and fast convergence.
	•	EIGRP for efficient routing in selected network segments.
	•	🖥️ End Devices: PCs, Laptops, Tablets, and Smartphones integrated into the network.
	•	📡 Wireless Access: Configured Access Points to connect mobile and smart devices.
	•	🛠️ Server Configuration: Mail Server, DHCP Server, and other critical services deployed for enterprise functionality.
	•	🔄 Redundancy & Reliability: Multiple paths configured to ensure fault tolerance and load balancing.
	•	🔐 Subnetting & IP Allocation: Proper subnetting used to optimize IP addressing and enhance network management.

This project demonstrates practical implementation of core networking concepts including IP addressing, VLANs, server configuration, and multi-protocol routing in a simulated enterprise environment.
